# NGA SDK for iOS

The Swift package of the NGA SDK: `NGASDK`, and `NGASDKRender` for games that show NGA's ads. This repository holds
only the package manifest; the frameworks are the zips on each version's release.

In Xcode, *File > Add Package Dependencies…*, enter `https://github.com/nga-io/nga-sdk-ios`, and choose the version.
A release candidate (`X.Y.Z-rc.N`) is a pre-release, which a version range does not pick up: name it with *Exact Version*.
